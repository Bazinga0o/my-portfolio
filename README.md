# David Ayodeji Adefioye Personal Portfolio

A multi-page, responsive static portfolio built with semantic HTML5, pure CSS, JSON data, and JSON-LD. No JavaScript or CSS framework is required.

## Pages
- Home
- About Me
- Educational Background
- Technical Skills
- Projects
- Hobbies & Interests
- Curriculum Vitae
- Contact Me

## Directory structure
```text
David_Adefioye_Portfolio/
├── index.html
├── about.html
├── education.html
├── skills.html
├── projects.html
├── hobbies.html
├── cv.html
├── contact.html
├── data/
│   └── data.json
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── images/
│   │   └── profile.jpg
│   └── docs/

└── report/
    └── Technical_Report.docx
```

## Deployment
Upload the folder to a GitHub repository and enable GitHub Pages from Settings > Pages, using the branch containing `index.html`. Netlify can also deploy the folder directly as a static site.

## Notes
The Contact form uses `mailto:` because the project is static and no server-side processing is included.
The Hobbies & Interests page deliberately avoids inventing personal hobbies not present in the supplied CV.
